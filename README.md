# Weather App 🌦️

A simple and responsive Weather App built using HTML, CSS, and JavaScript. It provides real-time weather information and a 5-day weather forecast for any city.

## 🌐 Live Demo

[Click Here to View Weather App](https://weatherapp-sandy-sigma.vercel.app/)

## ✨ Features

- Search weather by city name
- Current temperature
- Feels-like temperature
- Humidity information
- Wind speed
- UV Index
- Visibility
- 5-Day Weather Forecast
- Dynamic weather icons
- Error handling for invalid city names
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- Fetch API
- Async/Await

## 🔗 API Used

- Geocoding API – To get city coordinates.
- Weather Forecast API – To fetch weather information.
